In one sentence

RunnerPdf works entirely on your phone: it collects nothing, shares nothing, and cannot upload anything, because the app has no internet access at all.

Your files

RunnerPdf reads only the files you pick with the Android system file picker. A file is opened to run the tool you chose, the result is written to the app's private cache, and from there you decide where to save it or which app to share it with. Your documents are never sent to us or to anyone else. The app keeps no list of the files you have opened.

Permissions

  • No internet permission. The INTERNET permission is explicitly removed from the app, and our build fails if it ever comes back. Without it, neither the app nor any library inside it can open a network connection.
  • No storage permission. Files are chosen and saved through the Android system screens, which grant access to one file at a time.
  • No camera permission. Scanning uses the system camera app to take a picture; the photo is returned to RunnerPdf as a normal file.
  • No location, contacts, microphone, calendar or phone-state permission.

What we do not collect

RunnerPdf has no account, no login, no advertising, no analytics and no crash-reporting service. We do not collect:

  • personal information (name, email, address, phone number);
  • files, document contents or file names;
  • usage statistics, diagnostics or crash logs;
  • device identifiers or advertising identifiers;
  • location.

Google Play's Data safety section for RunnerPdf is declared accordingly: no data collected, no data shared.

Third-party components

RunnerPdf uses permissively licensed components that run locally:

  • PdfBox-Android (Apache 2.0): reads and writes PDF files;
  • AndroidX and Jetpack Compose (Apache 2.0): the interface;
  • Hilt (Apache 2.0): dependency injection;
  • ML Kit Text Recognition (Google ML Kit Terms): on-device text recognition for searchable PDFs. The model ships inside the app and runs offline; no image is sent to Google.

None of them has network access inside RunnerPdf. Their licences are listed in the app under Settings, Open-source licences.

Data retention and deletion

There is no server and no user profile, so there is no data for us to retain or delete. Temporary files live in the app's private cache and are removed by Android when space is needed. Android backups are disabled, so the app's files are not copied off the device by the system.

Children

RunnerPdf is not directed at children and collects no data from anyone, including children. It has no social features, no user-generated content and no purchases.

Changes to this policy

If a future version of RunnerPdf ever changes how it handles data, this policy will be updated before that version is released, and the effective date above will change.
